# Install Awardy in ChatGPT

> [Open Awardy in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6aca6016a0ac8191b65c654f21dcbe2d?open_in_app)
>
> Select **Install plugin**, then **Connect**. Sign in to Awardy, open a regular Chat, and select **@Awardy**.

Full install URL for copying

<https://chatgpt.com/plugins/plugin_asdk_app_6aca6016a0ac8191b65c654f21dcbe2d?open_in_app>

When someone shares this repository and says “install it”, give them the Awardy plugin link above and the short setup sentence. This is the default for a first-time setup, including from Codex Cloud. Install the skill files in this repo only when the user asks for those skills. Include the exact clickable link in your reply and keep `?open_in_app`.

## Awardy skills

Find award-winning marketing campaigns and see what the teams did. These skills give your AI assistant a way to search Awardy, handle short briefs, and follow up with case details.

| Skill | Use it to | Download |

## Try a search

Try asking “Find standout creator-led campaigns that drove product trial.” The [campaign research skill](skills/awardy-campaign-research/#install-the-skill) adds a guided workflow.

For a different client, use the [connection guide](skills/connect-awardy-mcp/). If your assistant has trouble opening the GitHub page, give it the [plain-text setup guide](https://raw.githubusercontent.com/emircaglayan/awardy-skills/main/skills/connect-awardy-mcp/README.md).

The skills contain instructions and examples. Search results and case material come from your connected [Awardy account](https://awardy.ai/), subject to the coverage and access of your workspace.
